# Used Car Price Prediction Dashboard

An end-to-end machine learning project for predicting used-car prices from Craigslist listings and exploring vehicle-market patterns through an interactive dashboard.

---
## Summary

The project uses an XGBoost regression model together with FastAPI, SQLite, JavaScript, Bootstrap, and Chart.js. The dashboard provides vehicle search, dataset statistics, model performance analysis, error analysis, and SHAP-based feature explainability.

The final model achieved:

**R²:** 0.917
**MAE:** $1,756
**RMSE:** $4,349
**MAPE:** 16.2%
**80.6%** of predictions were within **20%** of the actual listing price

---
## Dashboard
### Statistics
Overview of the dataset and major vehicle-market patterns.

### Vehicle Search
Search, filter, and inspect individual vehicle listings and predicted prices.

### Model Performance
Model metrics, prediction-error analysis, and global SHAP feature importance.
